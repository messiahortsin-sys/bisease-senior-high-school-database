Bisease Senior High School Database

Run locally:
1. Install Python 3.
2. Open a terminal in this folder.
3. Run: pip install -r requirements.txt
4. Run: python app.py
5. Open: http://127.0.0.1:5000

Modules included: dashboard, students, staff, attendance, fees, academic results.
For production, add login, role permissions, backups, audit logs and HTTPS.
